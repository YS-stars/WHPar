# WHPar
All packages required for reference are specified at the beginning of the file; please install them independently. The compatible Python version is 3.7.

Step 1: Run the test_mal() and test_beg() functions in the main.py file to obtain the API sequence and the API parameter sequence, respectively.

Step 2: Run the doc_vec() function in test3.py to perform the processing of the API sequence and parameters.

Step 3: Run the phash() function in test3.py for reprocessing the vectors, and execute the api_C() function to concatenate the API vectors and parameter vectors.

Step 4: Place the final file generated in Step 3 in the path /TextClassification/data/, and refer to the readme document under /TextClassification for subsequent operations.
